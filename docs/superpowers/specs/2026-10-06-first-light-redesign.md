## 1. What we are doing and why

The monitor is being repositioned from a portfolio project into a product for operations and procurement leads at mid-sized importers. Two things change together:

1. **Rebrand** from "SCM Disruption Monitor" to **Foreglow** (working name: likely, not legally cleared yet).
2. **Redesign** every screen in the **First Light** visual direction: warm paper ground, dark ink text, an editorial serif for headings, and one signal colour (ember) used sparingly.

Brand inputs that drive every decision:

| | |
| --- | --- |
| Promise | "See it coming." |
| Personality | Calm, precise, warm |
| Voice | Expert and measured. States exposure plainly, cites sources, never alarmist |
| Must not look like | Purple AI gradients or glowing orbs · corporate stock imagery · military/radar dashboards · cartoon or emoji-heavy UI |

The current UI fails the brief in specific ways this spec fixes: a dark navy screen flooded with red and orange cards, 90+ emoji used as icons, pulsing "LIVE" indicators, coloured left/top border accents on cards, and all-caps section labels everywhere.

### Non-goals (do not build)

- Marketing landing page, pricing page, email templates, pitch deck. Designed, but separate work.
- Dark theme. First Light ships **light-only** (section 3.5).
- Mobile-specific layouts. Keep the existing responsive breakpoints working; do not design new phone layouts.
- Any new feature, data source or copy generated by AI prompts.

### 2.3 Logo

The mark is first light breaking the horizon: a half sun, one arc of glow, one horizon line. SVG sources are in `first-light-reference/foreglow-mark.svg` and `foreglow-mark-small.svg`.

import { BRAND } from "@/lib/brand"

interface LogoProps {
  size?: number          // mark height in px, default 30
  showWordmark?: boolean // default true
  className?: string
}

export default function Logo({ size = 30, showWordmark = true, className = "" }: LogoProps) {
  return (
    <span className={`inline-flex items-center gap-2 ${className}`}>
      <svg width={size} height={size} viewBox="0 0 48 48" fill="none" aria-hidden="true">
        <path d="M6 30 A18 18 0 0 1 42 30" stroke="#E0A077" strokeWidth="2" />
        <path d="M12 30 A12 12 0 0 1 36 30 Z" fill="#B04A22" />

      {showWordmark && (
        <span className="font-serif text-[25px] leading-none text-ink">{BRAND.name}</span>

### 3.2 Typography

Two families, loaded with `next/font/google` (self-hosted at build time, no runtime request):

- **Newsreader** (serif): page and card headings, big numbers, recommendation titles, the wordmark. Weights 400 and 500, plus italic 400.
- **Public Sans** (sans): everything else. Weights 400, 500, 600.

Remove the Geist `localFont` setup from `app/layout.tsx` and delete `app/fonts/`.

| Role | Classes |
| --- | --- |
| Page headline (brief) | `font-serif text-[40px] leading-[1.1] font-normal text-ink` |
| Tab/page H1 | `font-serif text-4xl font-normal text-ink` |
| Card title (H2) | `font-serif text-[26px] leading-tight font-medium text-ink` |

### 3.3 Shape and spacing

- Radius: cards `rounded-xl` (12px); inner cards `rounded-[10px]`; buttons and inputs `rounded-lg` (8px); chips and filter pills `rounded-full`.
- Borders: 1px. No coloured side or top accent borders anywhere (`border-l-4`, `border-t-2` accents are removed; they exist today in `KPIBar`, `DisruptionFeed`, `AIInsightPanel`, `ImportProfileFlow`, `app/profile/page.tsx`).
- Shadows: none, except the chat panel (`shadow-lg`) and modal (`shadow-xl`).
- Card padding `p-6` (large sections `p-7`); gap between cards `gap-5`/`gap-6`; vertical rhythm between page sections `space-y-7`.
- Page container stays `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`.

### 3.4 Motion

- Remove every `animate-ping` and every `animate-pulse` on badges, dots and banners. `animate-pulse` remains only on skeleton placeholder blocks.
- Remove `hover:scale-*`. Hover states change border or text colour only.
- Keep the `cardEntrance` keyframe but wrap its use for reduced motion: in `globals.css` add `@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }`.

### 3.5 Light-only theme

Today `Navbar` toggles a `dark` class that Tailwind ignores (config uses the default media strategy), and most components hard-code dark slate.

- Set `darkMode: "class"` in `tailwind.config.ts` so OS dark mode can never activate stray `dark:` variants.
- Remove the dark-mode toggle button, its state and the `theme` localStorage read/write from `Navbar`.
- Delete every `dark:` variant class (they exist in `AIInsightPanel.tsx`, `app/about/page.tsx`, `app/page.tsx`).
- In `app/layout.tsx` add `export const viewport: Viewport = { colorScheme: "light" }` (import `Viewport` from `next`) so native form controls render light even when the OS is dark.

### 4.1 Severity system (one mapping for the whole app)

Three visual levels, always shown as a word in a chip. Levels differ in lightness as well as hue, so they survive colour blindness and greyscale.

| Level | Chip | Used for |
| --- | --- | --- |
| Critical | `ui.chip + ui.chipCritical` | Event severity 3 · advisor `CRITICAL` · inventory `critical` · structural `Critical` · HHI `critical` · health grade `Critical`/`Poor` |
| Warning | `ui.chip + ui.chipWarning` | Event severity 2 · advisor `HIGH` (label "HIGH") · inventory `warning` · structural `Elevated` · HHI `concentrated` · health grade `Fair` |
| Monitor | `ui.chip + ui.chipMonitor` | Event severity 1 · advisor `MEDIUM` (label stays "MONITOR") · structural `Watch` · HHI `moderate` |
| Positive | `ui.chip + ui.chipPositive` | Inventory `safe` · HHI `diversified` · health grade `Excellent`/`Good` · "No match found" · success messages |

## 5. Voice and copy rules

- No emoji or pictographs anywhere in the UI or PDF. Where an emoji was the only icon, drop it; the label is enough. Where a control needs an icon (close, chevron, search), use an inline stroke SVG (`fill="none" stroke="currentColor" strokeWidth="2"`), with `aria-label` on icon-only buttons.
- Allowed typographic glyphs as text: `→ ↑ ↓ · — ✓`. Replace `▼/▲` disclosure triangles with an SVG chevron. For price changes use signed numbers: `+2.6%`, `−7.0%` (U+2212 minus).
- Sentence case for headings, buttons and labels. No exclamation marks.
- Plain, measured statements. Examples:
  - "✅ Company profile saved! Your dashboard is now personalized." → "Profile saved. Your dashboard now reflects your supply chain."
  - "🤖 Analyzing global disruption signals with Gemini..." → "Analyzing today's signals…"
  - "Reorder Now" → "Order today"
  - "📍 X — YOUR SUPPLIER — 3 active events" → "X · your supplier · 3 active events"
  - "INDIRECT EXPOSURE via Y" → "indirect exposure via Y"
  - "Ask AI Analyst" → "Ask the analyst"
  - "Your regions: Clear ✓" → "Your regions are clear"
- Keep every existing honesty caveat (AI-sourced · unverified, "Reference · not live", "verify manually", sourced footers). Restyle them; never remove or soften them.
